# Open Source Notes

## Why the repo does not bundle Fab Academy images/videos

The goal is a ready-to-go GitHub repo that is fully open source. The firmware, docs, and diagrams in this repository are original and MIT licensed.

Some reference pages from the Fab Academy student work show **Creative Commons Attribution Non Commercial** notices. Non-commercial restrictions are not compatible with many open-source definitions and are not the same as MIT/BSD/Apache/GPL-style open-source licensing. For that reason, this repo links to those pages instead of redistributing their media or CAD.

## What is safe to publish in this repo

- Original firmware written for this repo.
- Original markdown documentation.
- Original SVG diagrams in `docs/media/`.
- Original CAD that you create yourself.
- External links to reference pages with attribution.

## What not to copy without permission

- Student photos.
- Student videos.
- Student CAD files.
- Page screenshots.
- Arduino sketches from the reference pages, unless you verify a compatible license or get permission.
