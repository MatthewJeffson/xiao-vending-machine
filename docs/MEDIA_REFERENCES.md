# Media References and Asset Policy

This repo is MIT-licensed and designed to stay fully open source. The Fab Academy reference pages include useful photos/videos, but the student pages explicitly show **Creative Commons Attribution Non Commercial** notices. Because that is not compatible with a fully open-source MIT repo, this package does **not** copy or redistribute their photos, videos, CAD files, or page assets.

Instead, this repo includes original SVG diagrams under `docs/media/` and keeps the Fab Academy media as external references.
